# Security Policy

The Free Video Editor runs entirely in your browser. Your media is never uploaded, so the most serious
problems would be anything that sends data off the device, runs untrusted code, or corrupts a project
file.

## Supported versions

Only the latest `main` is supported. Fixes land there first.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Email **contact@beestack.in** with:

- what the problem is and where (file, feature or URL)
- steps to reproduce, or a proof of concept
- the impact you expect

You will get a reply as soon as a maintainer can. Please give us a reasonable time to fix the problem
before you share it publicly. We will credit you in the fix if you want.

## Out of scope

- Findings that need a modified browser, or physical access to an unlocked machine.
- Missing hardening headers with no demonstrated impact.
